MINDS Leavitt Open dashboard

Revisiting the Bavelas-Leavitt Experiment

Distributed SLM agents search for one shared figure.

This project coordinates Jetson devices running local Ollama models. A dashboard server assigns private figure cards, controls communication topology, streams every message, and records whether the agents identify the one figure shared by all participants.

Runtime Python + static HTML/CSS/JS
Agents 2-5 Jetsons
Model Local Ollama / Gemma
Protocol Newline-delimited JSON over TCP

What it does

The experiment loop

1

Assign private figure cards

The server samples figures so exactly one symbol is common to every active agent while each agent still has a private list.

2

Route topology-limited turns

Broadcast, circle, chain, Y, and wheel modes decide which agents can see or receive each message.

3

Ask local SLMs for actions

Each Jetson builds a prompt from its state and visible history, calls Ollama, and returns either CHAT or ANSWER.

4

Score and display results

The dashboard shows live routes, chat history, model settings, submitted answers, and success or failure.

Jetson client

Main/client.py

Runs on each Jetson. It connects to the server, performs the hostname handshake, receives turn payloads, calls Ollama, parses the model response, and returns structured actions.

Calls
Local Ollama at 127.0.0.1:11434.
Returns
CHAT messages, ANSWER submissions, timeouts, and status events.

Build topology-specific prompts and parse model output for private-message modes. Each file encodes who the agent can contact and how messages should be formatted.

Shared prompt text

Centralizes common prompt sections: experiment introduction, allowed figures, recent history, current state, answer rules, and output format instructions.

Site/

The live presentation layer and server entry point. Run Site/dashboard_server.py to serve the dashboard and listen for Jetsons.

Main/

The Jetson-side runtime. Copy or sync these files to devices so each one can connect back to the dashboard server.

Public-Demo/ and Demo/

Static versions of the dashboard experience for demonstrations without live Jetson clients.

Old/

Archived server, client, and prompt experiments. The restored light prompt snapshot documents a previous prompt style.

outputs/

Generated walkthrough slides and overview artifacts used to explain or present the project.

notes.txt

Quick run instructions for the Jetson network setup, including the dashboard command and browser URL.
